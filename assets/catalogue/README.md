# Catalogue fabric images — Book 2

Drop one generated image per fabric into this folder, named **exactly** as the
`Expected file` below. The catalogue (`catalogue.js`) builds each fabric's image
path as `assets/catalogue/<slug>.jpg`, where `<slug>` is the lowercased,
hyphenated fabric name. If a file is missing, the card falls back to the serif
monogram automatically (via `onerror`), so nothing looks broken.

- Format: **JPG** (`.jpg`), the filenames below are required.
- Source: "Real ASA Fabric Inventory" Google Sheet, Book 2 page tabs.
- Names are verbatim from the sheet's page-level `Item` field. Only the eight rows
  with real design names are catalogued; the sheet's generic page labels
  ("Book 2 swatch page 0N" / "Book 2 packing list page NN") were dropped.
